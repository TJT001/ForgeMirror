## runtime/android/README.md

# Android 运行时

- stub/src/main/java：Java 系统入口和组件代理。
- bootstrap/src：最小引导和信任链。
- core/src：C++17 实现。
- include/forgemirror：版本化 C ABI 公共头。
- art-adapters：按运行时特征选择适配器。
- platform：JNI、模块、路径和平台能力适配。

C++ 类型与异常不跨 C ABI。首轮使用 Pixel 5 API 30 验证，其他版本须单独记录。尚未生成 Gradle/CMake 工程，避免未确定工具链版本的伪构建配置。
