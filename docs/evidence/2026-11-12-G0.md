## 规格签字说明

- 当前规格由实现侧按设计文档 v1.7 形成，作为 P0 实现依据；没有独立评审人签字。
- 容器、清单、策略格式均为 **P0 草案**，P1 双端联调后再冻结；冻结前允许修订。
- 清单规范化目前是排序 JSON 子集，不是完整 RFC 8785 JCS；已在 ADR-0001 记录。

## 遗留项

1. 容器格式冻结：P1 完成 Python/C++ 联调、负例和 manifest 覆盖后冻结。
2. Android 运行时容器解密：P1-A3/B4 实现，当前 `core.cpp` 只做生命周期与错误码。
3. 清单 JCS：P1 替换为 RFC 8785 实现并补跨语言向量。
4. 策略/规则包：策略已有 Python 打包/验签；规则包仅占位，P3 实现。
5. 设备矩阵：仅 Pixel 5 / API 30；API 26/27、16 KB 设备、厂商 ROM 在 P4 扩展。
6. 发布签名：G0 只验证 unsigned release 对齐，客户签名/HSM 流程在 P2。
7. 供应链：`cryptography`、OpenSSL、BoringSSL 仍为 candidate，发布前固定 commit/校验和/许可。
