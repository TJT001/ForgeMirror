# 2026-11-13 P3：S4 规则包与规则扫描

## 范围

PKR1 规则包编解码、壳内规则加载、APK 内 so 字符串扫描、S8 A4 闸门。

## 实现

| 模块 | 内容 |
|---|---|
| `formats/rules.py` | PKR1 打包/解包：HKDF + AES-GCM + ECDSA raw/Ed25519 签名；JSON 载荷校验 |
| `ShieldRules.java` | 规则包验签/解密、all/any 字符串规则、APK 内 `lib/**/*.so` 扫描 |
| `ShieldSignature.java` | 策略与规则共用的分离签名校验（ECDSA raw→DER、Ed25519） |
| `protect.py` | 生成默认规则包并注入 `assets/shield/rules.pkr`，纳入清单产物 |
| `gate.py` | A4：规则包验签 + 错误密钥拒绝；不再标记 inconclusive |

## 验证

### 规则包

Python 40 项测试通过（新增 PKR1 往返、错误密钥、错误公钥、非法规则）。

### S8 闸门

```text
a4_rules_signature pass
a4_rules_key_required pass
passed: true, failed: []
```

### 设备（Pixel 5 / API 30）

```text
ShieldRules: loaded 2 rules
ShieldRules: rule matched: demo_jni in lib/arm64-v8a/libdemo.so
ShieldRules: rule matched: demo_jni in lib/armeabi-v7a/libdemo.so
ShieldRules: rule matched: demo_jni in lib/x86/libdemo.so
ShieldRules: rule matched: demo_jni in lib/x86_64/libdemo.so
ShieldRuntime: rule scan done matches=[demo_jni x4] ms=213
```

- 规则扫描在后台线程，不阻塞首帧；
- 裁剪后的业务 so 仍保留 JNI 符号，规则命中符合预期；
- A4 闸门由 inconclusive 转为 pass。

## 限制

1. **YARA 已接入**（见 `2026-11-13-P3-yara.md`）：壳内 YARA 4.5.4 + 九条演示规则；研究侧九规则与产品规则语义仍待补。
2. **默认字符串规则是演示规则**（`demo_jni`、`frida_like`），不是产品九规则；九条规则仍受来源与许可约束。
3. **扫描对象是 APK 内 lib**，尚未扫描 `/proc/self/maps` 的已加载模块和匿名内存。
4. **事件已接入本地队列与上报**（见 `2026-11-13-P3-events.md`），但响应分级与阻断动作未实现。
5. 规则热更新与版本门控未实现。
