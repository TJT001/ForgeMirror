### 真实 APK

输入：`android/app/build/outputs/apk/debug/app-debug.apk`

```bash
PYTHONPATH=backend/pipeline python3 -m forgemirror.cli build \
  --apk android/app/build/outputs/apk/debug/app-debug.apk \
  --out artifacts/p1a-demo --profile basic \
  --signing-mode customer_local \
  --build-id 00112233-4455-6677-8899-aabbccddeeff
```

结果：

- 包名 `dev.forgemirror.demo`，7 个 DEX；
- 容器 `container.fdx` 12,470,704 字节；
- SHA-256 `edbe70775e59ecaed5639c4be91fd185394e714d2f24c9b15c0fba88654c6089`；
- Python 自测：7 个 DEX 与 APK 内原始文件逐字节一致；
- C++ 宿主读取器独立解密该容器：`PASS "case" (7 files)`；
- 输出：`intake.json`、`inventory.json`、`container.fdx`、`dex_manifest.json`、`build.meta.json`、`keys/k_content.bin`。
