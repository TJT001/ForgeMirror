# 2026-11-13 P3：YARA 引擎与产品规则语义

## 范围

固定版本 YARA 4.5.4 的 Android 构建与 JNI 接入；壳内规则包 `yara` 字段；
host 侧产品规则的编译、正反例与缺一特征测试。

## 实现

| 模块 | 内容 |
|---|---|
| `third_party/yara/` | YARA 4.5.4 源码（BSD-3，保留 COPYING）；仅编译核心与 `tests/math/time/console/string/dex` 模块 |
| `yara_jni.cpp` | JNI 编译/扫描/销毁；`yr_initialize` 于 `JNI_OnLoad`；错误通过 `IllegalArgumentException` 返回 |
| `ShieldYara.java` | 规则编译与 `byte[]` 扫描，`System.loadLibrary("shield_yara")` |
| `ShieldRules.java` | 规则包存在 `yara` 字段时优先用 YARA 扫描，否则回退 all/any 字符串规则；编译失败回退 |
| `formats/yara_rules.py` | host 侧引擎：十条独立编写的产品规则、编译、`scan_bytes`/`scan_apk` |
| `protect.py` | 默认规则包写入 `yara` 源码（十条 + 演示规则 `fm_demo_jni`） |
| `cli.py` | `yara-check`、`yara-scan` 命令 |

## 构建取舍

- PE/ELF/hash 模块依赖 OpenSSL/CommonCrypto，Android 构建未引入 crypto 后端，因此排除；
  使用 `pe.*` / `elf.*` / `hash.*` 的规则会编译失败，当前十条规则只用字符串特征。
- 进程内存扫描（`USE_NO_PROC`）未启用，当前只扫描 APK 内 `lib/**/*.so`。
- 固定版本 `v4.5.4`，与 host 侧 `yara-python 4.5.4` 对齐。

## 十条产品规则

| 规则 | 语义 | 条件 |
|---|---|---|
| `fm_dynamic_instrumentation` | Frida/Gum 字符串 | any |
| `fm_xposed_framework` | Xposed/LSPosed/EdXposed | any |
| `fm_root_shell` | su/Superuser/Magisk 路径 | any |
| `fm_debugger_attach` | ptrace/TracerPid/waitForDebugger | 2 of them |
| `fm_emulator_artifact` | goldfish/ranchu/qemu | 2 of them |
| `fm_hook_framework` | Dobby/ShadowHook/bhook | any |
| `fm_dex_memory_loading` | 内存 DEX 加载特征 | 2 of them |
| `fm_signature_tamper` | 签名查询特征 | 2 of them |
| `fm_network_interception` | tcpdump/mitmproxy/Burp | any |
| `fm_unpack_framework` | youpk/fupk3/yarfahook/FART dump 符号 | any |

这些是**独立编写的演示规则**，不是研究侧九条语料，也不是最终产品规则。

## 限制

1. 十条规则是演示语义，研究侧语料与产品规则的正反例、来源/许可记录仍未完成。
2. 排除 PE/ELF/hash 模块；依赖这些模块的规则不可用。
3. 未启用进程内存扫描与 `/proc/self/maps`，仅扫描 APK 内 so。
4. 规则热更新、版本门控与原子替换未实现。
5. 远端进程也会编译/扫描规则，事件仅在主进程上报。
