# 独立实现与行为等价原则

ForgeMirror 研究逆向分析中遇到的加固功能，自主编写实现，以可验证的行为和功能等价为目标。研究与开发可由同一人员、工具或模型会话完成，可以直接参考已有逆向结论、接口、格式和实验结果。

1. 保留必要的功能说明、来源章节和对照测试，服务于实现及验收；流程按任务规模安排。
2. 不直接复制未经授权的原厂源码、反编译代码或二进制实现；不把原厂私钥及未经授权的专有资产打包进产品。公开标准和获准使用的开源组件按其许可复用。
3. 规则、特征和兼容字段按实际来源及使用权处理；研究证据与产品交付资产分别确认。
4. 等价验收关注接口、状态转换、文件语义、兼容性与错误行为，无需复现原实现的指令、控制流或缺陷；增强与偏差在测试中说明。
5. 开源依赖遵守设计 §18 的许可和署名要求，保留必要的来源与第三方声明。
