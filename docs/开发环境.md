## 工程状态

- 工程位于 `android/`，包名 `dev.forgemirror.demo`，Java + C++17，minSdk 26。
- `android/shield/` 已建立 `shield_boot` 与 `shield_core` 两个 native target；C ABI v1 头文件位于 `src/main/cpp/include/forgemirror/`。
- `:shield:assembleDebug`、`:app:assembleDebug` 与 `:shield:testDebugUnitTest` 已通过；`ShieldRuntimeTest`、`YidunProbeDeviceTest` 已在 Pixel 5 与 API 37 模拟器运行。
- PKR1 远程更新已实测：v3/v4 拉取、篡改拒绝、版本门控；见 `docs/evidence/2026-11-21-P3-pkr1-remote-update.md`。
- 构建检查：`backend/pipeline/scripts/check-env.sh`；一键检查：`backend/pipeline/scripts/check.sh`。

## 常用验证命令

```bash
# Android 单元测试
cd android && ./gradlew :shield:testDebugUnitTest

# 设备测试（易盾探针 + PKR1 载荷解析）
ANDROID_SERIAL=<serial> ./gradlew :app:connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=dev.forgemirror.demo.YidunProbeDeviceTest

# 后端 + 流水线全量检查
backend/pipeline/scripts/check.sh

# 本地 API（远程规则更新）
docker compose -f backend/docker-compose.yml up -d postgres
(cd backend && go run ./cmd/api)
adb reverse tcp:8080 tcp:8080
```
